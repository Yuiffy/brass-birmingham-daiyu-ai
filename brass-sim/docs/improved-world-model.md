# 世界模型改进与独立复测

本篇保留上一轮架构改进记录；当前默认权重已继续训练为纯终局分数目标，见[分数续训实验](score-training.md)。本篇“当前”指该历史实验完成时。

2026-09-15。本次已完成训练、独立比赛和游戏接入。当前 `world_model/models/` 使用结构化世界模型＋终局价值网络，新增可选的“学习增强搜索”。旧版权重与历史实验仍保留。

## 实际棋力结果

每次400局，100个新种子组、每组4局轮换座位。起始种子28000001，深度2、根候选宽度8。并列冠军平分一次胜利。所有模型在比赛前冻结；神经网络对手的文件SHA-256在各组一致。

| 四人阵容 | 原启发式 | 原搜索 | 神经网络 | 世界模型 |
|---|---:|---:|---:|---:|
| 旧版世界模型 | 14.00% | 44.13% | 21.63% | 20.25% |
| 新版世界模型 | 11.00% | 19.88% | 14.38% | **54.75%** |

世界模型升级后，胜率增加34.50个百分点，95%区间[28.25, 40.63]；平均VP从72.53升至88.47，增加15.94，区间[13.39, 18.44]。新版世界模型相对同场神经网络的胜率差为40.38个百分点，区间[33.63, 47.13]。

再把原启发式的位置换成学习增强搜索，完成另一组400局：

| AI | 胜率 | 平均VP |
|---|---:|---:|
| 学习增强搜索 | **34.38%** | 73.38 |
| 世界模型 | 24.50% | 74.12 |
| 原搜索 | 22.50% | 73.92 |
| 神经网络 | 18.63% | 73.09 |

学习增强搜索相对原搜索的胜率增加11.88个百分点，区间[4.13, 19.25]；相对世界模型增加9.88个百分点，区间[1.88, 17.63]。它的平均VP并未可靠提高：相对原搜索为−0.54，区间[−3.32, 2.16]。

两套阵容不能按胜率直接横向排名。结果说明本项目中的两个改进版本有效，不能推论世界模型架构普遍优于神经网络，也不能把四人夺冠率当成一对一胜率。

区间使用20,000次bootstrap，以同种子的四局为整体重采样，版本间配对。它覆盖棋局种子抽样波动，不覆盖不同训练随机种子、其他对手策略或隐藏手牌设置的变化。共同深度/宽度不等于相同计算预算：第一套新版比赛中，世界模型约37.71ms/步，原搜索18.00ms/步，动作网络0.30ms/步；并行运行时存在CPU争用。

完整逐局结果、文件哈希与区间：[improvement.json](../world_model/reports/improvement.json)。统计代码：[compare_improvement.py](../world_model/compare_improvement.py)。

## 预测进步

预测测试使用10,000局数据中按顺序编号101–200的100局test游戏，共12,800条transition；它们与训练、验证游戏分离，也不同于先前用于诊断的前100局测试游戏。两版使用完全相同的测试游戏和递归窗口。

| 指标 | 旧10k差分模型 | 新结构化模型 |
|---|---:|---:|
| 标准化单步MSE | 0.00345351 | **0.00057112** |
| 下一行动玩家准确率 | 21.98% | **96.51%** |
| 金钱MAE / 英镑 | 6.070 | **0.861** |
| 变化检测精确率 | 34.36% | **93.43%** |
| 变化检测召回率 | 80.49% | **91.31%** |
| 变化检测F1 | 48.16% | **92.36%** |
| 五步递归标准化MAE | 0.06934 | **0.00492** |

同一五步窗口的“状态不变”基线MAE为0.02111。递归测试沿记录中的合法动作描述运行，每一步状态来自上一步预测；动作及其成本来自真实动作记录，因此这项测试仍比自由规划简单。游戏内自由规划另外通过真实终局比赛检验。

## 改了什么

原模型对689个状态字段统一回归变化量。稀疏棋盘中，大多数元素不变；回归容易扰动无关字段。下一行动玩家需要离散选择，原回归输出经常让多个玩家同时接近0.5。仅增加训练轮数/数据没有解决这些问题。

新版保留原来的689维状态、147维动作与规则引擎，分别学习：

1. 条件变化量：836→128→689的MLP，预测发生变化时改变多少。
2. 变化门：836→128→689的MLP，用加权二元交叉熵学习哪些字段变化；门未开启的字段精确保留当前值。
3. 离散控制：64→96→多分类输出，预测下一玩家、回合、时代、牌堆数量、回合顺序等。64维输入仅来自当前公开回合/经济信息与当前动作，没有下一状态字段。
4. 终局价值：109→64→1的MLP，基于当前局面的角色相对特征预测 `finalVP[player] - 0.25 * max(finalVP[opponents])`，输出以100缩放。终局成绩仅作为训练标签；推理输入不含未来成绩。

变化量尺度、变化频率和类别权重只从训练集估计。门阈值固定0.35；控制分类使用argmax。结构化投影用预测的回合顺序和牌堆数量建立假想局面，不读取真实未来牌序。

世界模型型在学习到的状态转移中规划，以终局价值网络评价分支；学习增强搜索保留原规则引擎转移，使用同一个价值网络评价叶子。原搜索和直接动作评分网络保持原策略。真实落子、时代转换与计分始终由原游戏规则执行。

方法参考：[DreamerV3](https://arxiv.org/abs/2301.04104)中对不同预测目标使用不同分布/损失的设计，以及[MuZero](https://arxiv.org/abs/1911.08265)把价值预测与规划连接的思路。本实现是依赖NumPy的小型监督学习实验，没有实现这两篇论文的完整算法，没有策略强化学习或MuZero自博弈。

## 训练与开发消融

复用10,000局数据池：8,000局 / 1,024,000条transition训练；权重选择仅使用原100局验证集。结构化动力学从头训练24轮，batch512，学习率0.001余弦降至0.0001，随机种子42，耗时约1,223秒。选中第23轮，依据为单步验证MSE＋0.1×三步验证MSE。

终局价值网络使用相同8,000局训练，每16步抽样并加入终局，四个玩家视角共288,000条训练样本；32轮、batch1024、hidden64、种子73，最佳第23轮，验证RMSE约16.27 VP单位。动作网络固定为此前expanded-10k版本。

开发比赛使用种子800001、80局，并未混入上述最终400局统计：

| 开发配置 | 世界模型胜率 |
|---|---:|
| 1k结构化动力学＋旧启发式估值 | 13.75% |
| 同一1k动力学＋学习的终局价值 | 48.75% |

这个消融解释了为什么“预测更准”还不够：第一版虽然预测准确率提升，棋力反而下降；加入对长期终局收益的学习后才改善。开发赛用于确定方案，不作为独立成功证据。最终10k动力学与价值权重在新种子比赛前已冻结；没有根据最终比赛再挑选轮数或改参数。

## 在游戏中使用

```sh
npm run worldmodel:demo -- --port 8086
```

打开游戏，刷新以加载新权重。每位玩家可选择“世界模型型”或“学习增强搜索”。对战实验室支持两套四人阵容、保存的400局结果、任意新种子对战、逐局成绩导出、留出预测评估和历史版本切换。

“AI推演 / 预测对照”仍提供候选未来、真实规则副本对照、递归误差与真实执行按钮。世界模型规划不调用原状态转移；对照面板单独调用规则引擎以显示真实答案。

## 复现与继续训练

仓库保留最终权重、匹配的Adam状态、配置、逐轮日志、开发实验和独立报告。数据二进制保存在本地 `world_model/data-10k/`，约7.3GiB，不纳入Git。运行训练需要Python＋NumPy；游戏端只需Node/浏览器。

下面使用新输出目录以保留现有实验。若已有数据，不必重新生成。

```sh
node world_model/cli.js generate --games 10000 --players 4 --seed 1701 --ai mixed --out world_model/data-repro-10k
node world_model/cli.js train-structured --data world_model/data-repro-10k --validation-data world_model/data --epochs 24 --out world_model/repro-structured/models
node world_model/cli.js train-value --data world_model/data-repro-10k --validation-data world_model/data --epochs 32 --out world_model/repro-value
node world_model/cli.js compose --dynamics world_model/repro-structured/models --value world_model/repro-value --out world_model/repro-combined/models
node world_model/cli.js evaluate --data world_model/data-repro-10k --test-start 100 --test-games 100 --models world_model/repro-combined/models --out world_model/repro-combined/reports
node world_model/cli.js benchmark --models world_model/repro-combined/models --games 400 --seed 28000001 --depth 2 --width 8 --workers 4 --out world_model/repro-combined/reports/final-400.json
node world_model/cli.js benchmark --models world_model/repro-combined/models --types search,guided,neural,world --games 400 --seed 28000001 --depth 2 --width 8 --workers 4 --out world_model/repro-combined/reports/guided-final-400.json
```

继续训练当前动力学（保留现有价值头，恢复三个匹配的Adam状态）：

```sh
node world_model/cli.js train-structured --data world_model/data-10k --resume world_model/models --epochs 24 --lr 0.0001 --out world_model/next-run/models
```

旧结构化文件若未存变化损失权重，会从本次指定的训练集重新统计；它不影响已有推理权重。日志记录每个优化器是否恢复。`--resume`写入新目录，并把续训前权重纳入验证选择，避免最后一轮变差时覆盖更好的模型。旧的 `train` 命令只用于普通差分模型，会拒绝结构化权重，防止丢失辅助头。

当前仍有边界：模型只学习此项目已有实现；训练和胜率验证限定4人且所有当前手牌公开；2/3人可运行但未验证棋力；固定候选生成限制仍在；误差可能在更深推演中累积；尚未用多个训练随机种子验证稳定性。后续若调参，应使用新的开发种子，并另留新的最终比赛集。
