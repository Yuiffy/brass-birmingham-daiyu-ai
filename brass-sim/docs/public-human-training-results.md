# 公开真人意图与回合动力学：第二轮训练

日期：2026-10-10。上一轮 PR #1 已合入；本轮与 Manila 分支隔离。

## 数据来源与边界

这次实际找到并合法重放了 [Quasrain-Coder/BrassBirmingham](https://github.com/Quasrain-Coder/BrassBirmingham/tree/d3d269746863ee720cd797608ad2131edf277fae)
固定提交中的 6 场匿名四人真人对 AI 记录，均有 124 个行动，其中真人席位各合计 62 个。
另有一场双人真人记录与一场全 AI 四人记录，仅用于原生引擎审计。

原生 `applyAction` 全程启用合法性检查，必须按记录的玩家和顺序到达终局；发现不完整、非法、
矛盾席位标记或重复种子就中止导出。真人身份依赖来源文件的席位标记，棋手高手身份没有核实。
匿名玩家可能重复出现，整局切分不能证明对新棋手的泛化能力。

训练/验证/测试按整局固定切为 4/1/1 场，分别 248/62/62 条真人意图。
模型输入为 63 个公开经济、棋盘和自身手牌数量/万能牌标志；不使用对手手牌内容、未来抽牌顺序、
私人对局原始日志或终局分数。外部引擎的组合产业牌、多商人和资源选择与我们的 JS 引擎存在差异，
因此只迁移 18 类动作意图，不声称逐动作重建了本引擎轨迹，更不把外部终局分数当作 JS 价值标签。

本机私有 SQLite 中 10 场记录也经过结构审计。只有一场出现终局快照，但它有重复结束回合/
跳过玩家等异常；其余不完整。这些记录没有作为完整轨迹用于训练。只发布数量、异常统计和源哈希。

## 训练与开发实验

真人意图 MLP 使用训练集归一化，隐藏层 32，160 轮训练，通过验证交叉熵选中第 11 轮。
验证交叉熵 2.404（常数先验 2.664），测试交叉熵 1.974（常数先验 2.368），测试 top-1 命中率 40.3%。
只有一场验证和一场测试，分类结果不能直接证明棋力提升。

意图偏好接入当前合法动作上的有界根节点加分：相对于训练类频率的对数比值截断在 ±3，
权重上限 2；权重 0 复现原候选。策略保持 `human-card-v2` 与上一轮教师价值权重，
不替换合法动作生成或真实引擎搜索。对未来牌序和对手手牌的特征不变性已测试，
但现有世界模型/引导搜索本身仍采用所有手牌公开的实验设定。

同一批开发种子上，权重 0/.5/1/2 的均分依次为 130.375/132.125/129.5/130.0625。
正权重是一个候选对三个教师＋保牌参照，0 是参照自对弈。预先记录的选择规则选中 .5，
小样本分数仅用于候选选择，不作为最终提升证据。

世界模型只重新训练分类回合控制头，新增完整动作编码和公开产业消耗数量输入，100 轮。
棋盘变化门、产业/铁路回归和价值头保持原权重，不通过真实引擎修补世界模型的后继状态。
验证以关键回合字段错误加权选模型，避免总体 MSE 掩盖轮换错误。
上一轮预测留出集在本轮明确改列开发材料；其中下一位玩家准确率约 86%→95%，
轮数约 86%→98%，牌堆数量约 72%→92%，铁路字段约 87% 保持原样。
这些数字不是本轮新的独立证据。世界模型开发比较为 53.56 对 49.38 分，仍有零分局。

测试日志记录真实结算前棋盘上的未售产业/资源、研发后有无同产业更高等级建造、
铁路开局可见的现金/酒/双铁路合法候选数量。原因标记可能重叠，不把“无合法双铁路”
直接解释成单一酒或煤短缺。原始动作和资源目标保存在日志中，可核查行动选择。

## 冻结后的独立测试

候选、参照、模型和执行源码先冻结，再生成新的种子。策略固定对手、参照自对弈、候选自对弈
各 30 个独立种子组、四席轮换，120 局；另有 40 局世界模型同桌座位平衡比较，
40 场完全独立的合成教师预测轨迹。置信区间按种子组 bootstrap，重复自对弈轮换不当作独立样本。

40 场新预测留出集共 4,960 条转移，下一位玩家准确率 86.45%→95.04%，
轮数 85.28%→97.02%，牌堆数量 72.24%→91.01%，行动预算 99.56%→100%。
研发后下一位玩家准确率 72.70%→94.54%。由于没有重训棋盘变化头，
铁路字段完整取整匹配率仍为 89.54%，产业消耗数量仍为 95.48%，现金 MAE 仍为 £2.06。
整张手牌计数同时精确约 24.9%，其中包含未来随机抽牌的不确定性，不能把全部错误都归因于模型不足。

世界模型新/旧版在同桌座位平衡比较中分别为 48.7/50.3 分，差值 -1.6 分，
按 10 个种子组的 95% bootstrap 区间为 [-12.625, 8.225]。两版都有零分局。
这项比赛是一新一旧模型共同面对两个教师＋保牌版，不是两种纯自对弈的成对比较。
回合单步预测改善没有转化为完整对局改善，新控制头不替换默认世界模型。
本轮没有证明回合错误就是低分的主要原因；铁路/产业/资源预测和长链误差仍需要下一轮独立实验。

全部 400 场比赛和 40 场预测轨迹完成，没有依据最终测试继续调参。

| 场景 | 均分 | 均分 95% 区间 | 10% 分位数 / 最低分 | 低于 100 | ≥140 / ≥150 | 每步耗时 |
| --- | ---: | --- | --- | ---: | --- | ---: |
| 教师＋保牌参照自对弈 | 127.77 | [125.36, 130.17] | 107 / 78 | 6.67% | 26.67% / 15.00% | 213 ms |
| 真人偏好对三个参照 | 131.43 | [128.81, 134.13] | 111 / 93 | 1.67% | 30.83% / 14.17% | 214 ms |
| 真人偏好自对弈 | 129.03 | [127.27, 130.82] | 110 / 90 | 2.50% | 20.83% / 10.83% | 217 ms |

固定对手的同种子同座位配对增益 +3.67 分，95% 区间 [0.10, 7.12]：
有针对这个固定参照阵容的小幅改善证据，但下界接近零。
自对弈配对增益 +1.26 分，区间 [-1.675, 4.183]，没有证实均分提升。
自对弈低分比例下降，但 ≥140/150 的比例也下降；不能宣称全面变强或稳定达到 140–150。
固定对手胜率（平分胜利计数）为 30%。耗时来自同一机器上的并行实验，不能视为单线程稳定延迟。
默认浏览器版和默认世界模型均不晋升；真人偏好保持显式可选命令行实验。

真实结算诊断显示，参照/偏好自对弈的平均未售产业数在运河结束分别为 0.183/0.133，
铁路结束为 0.358/0.267；研发后未有同产业更高等级建造的数量为 0.925/0.700。
世界模型该项为 3.225，运河结束未售产业为 1.075，实际铺路行动仅约 3.15 次。
这些是观察到的损失模式，尚不构成它们导致低分的因果证明。

## 复现

`world_model/experiments/public-human-20261010/` 保存来源审计、压缩派生意图、训练记录、模型、
冻结源码和协议。外部引擎实现/整仓库及私人原始 SQLite 不复制发布。
原生源提交、源树和编译模块哈希已记录，编译方式见审计文件。
本轮控制训练复用上一轮已发布的合成教师数据，可从其 reproducibility 目录解压 float32 数据。
重新运行正式测试前，将 `frozen-source.zip` 解压到 `brass-sim/`，保留冻结时的文件字节和行尾；
Git 在 Windows/Linux checkout 时可能改变行尾，从而改变源哈希。

```powershell
python world_model/train_human_intent.py --data <解压后的真人派生数据目录> --out <新目录>
python world_model/train_critical_controls.py --data <augmented-resource-v2> --validation-data <augmented-resource-v2> --model world_model/experiments/human-teacher-20261009/models/world-model.json --out <新目录> --epochs 100
node world_model/human_benchmark.js --games 120 --seed <protocol.json的seed> --lineup intent,trainedcards,trainedcards,trainedcards --models world_model/experiments/human-teacher-20261009/models/world-model.json --intent-prior world_model/experiments/public-human-20261010/human-intent.json --intent-weight .5 --out <结果文件>
```

新的真人偏好和控制模型目前作为命令行实验选项交付；浏览器仍使用上一轮教师版。
