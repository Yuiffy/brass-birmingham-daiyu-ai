# 马尼拉 AI 实战比较 · 2026-10-07

本轮完成 **11,520 局完整原版基础规则对战**，覆盖 3 / 4 / 5 人，30 项规则与比赛测试通过。每个真实动作经过合法性验证，现金 / 抵押 / 股票守恒检查全部通过；失败和截断均为 0。规则边界的正确性以测试与已有规则书审计为依据，大规模对局本身不能证明所有规则正确。

目前证据最明确的是：面对这组固定启发式对手，**把均衡竞价上限增加 3 比索，优于减少 3 比索或维持原值**。精确模型前瞻在三个规模的财富配对差均为正，但四、五人局的区间仍跨 0。这里没有训练 MuZero，也没有证明人类高手水平或均衡最优出价。

## 三、五人与同桌竞争

三人局积极竞价均分 132.39、胜率 55.3%，均衡为 123.05 / 31.3%；前瞻为 128.68 / 28.1%。前瞻的财富共同种子差 +6.35，区间 [+0.93, +11.77]，但这不自动意味着胜率也提高。

五人局前瞻均分 99.56、积极竞价 99.27、均衡 93.30；各自胜率 28.1% / 38.7% / 20.8%。前瞻与积极的全样本均分接近，样本量又不同，不能声称前瞻更强。前瞻相对均衡配对差 +4.31 [−0.46, +9.08]；积极相对均衡 +5.98 [+1.51, +10.44]。

## 对船长出价的启示

积极策略仅改变竞价上限（均衡 +3），部署与装载仍与均衡一致。四人挑战赛中，它平均获得 5.25 次船长权，占平均 5.32 航次约 98.5%；四人混合赛也达到约 98.7%。这使它能持续购股和控制装载。保守策略在本轮两个环境中均未获得船长权，不能把它的结果解释成“稍微少付一点船长费”。

四人挑战赛中，积极策略实际成交价均值 **14.74**、中位数 **16**、P05–P95 为 **11–18 比索**；四人混合赛则为 **14.46 / 15 / 10–18**。这是所用固定对手竞价政策形成的**成交分布**，并非最佳报价区间，也不是这些价格在任意局面都划算的证明。没有比较更高上限、多个积极对手互相抬价，或对手自适应后的结果。

融资成本很明显：四人挑战赛积极策略终局平均抵押 **5.54 股**，均衡 **1.65 股**，前瞻 **1.38 股**。混合赛积极策略最低出现 −50 分，虽然负分只占约 0.10%，仍显示接管船长与贷款的尾部风险。四人挑战赛恰好没有它的负分样本，不能据此断言没有下行风险。

已有的 [初始局面反事实定价实验](../../EXPERIMENT-2026-10-07.md)估计“以某价确保赢得船长”对比“现在退出”的完整终局增益；本轮则测试实际竞价、成交和终局。这两项实验回答不同问题。**本轮支持适当提高原均衡上限，尚不能给出脱离手牌 / 市价 / 现金 / 对手的通用合理价格范围。** 后续应对上限做更密的扫描，并加入多位积极对手，再按状态评估条件价值与成交概率。

## 策略与实验设计

| 策略 | 实际区别 |
| --- | --- |
| 均衡 | 原启发式，包含股票远期估计和船员收益未来分摊 |
| 保守 / 积极 | 仅将均衡竞价上限减 / 加 3 比索 |
| 即时收益 | 当前部署即时净期望，不预测未来分摊；装载去掉股票远期期权估计；竞价沿用均衡 |
| 随机部署 | 在合法部署中均匀随机，包括停止；其他阶段沿用均衡 |
| 模型前瞻 | 最多 4 个启发式候选 × 8 个样本，重采样对手隐藏初始股，精确模拟到本航次结算，叶估值加入股票远期启发式；竞价沿用均衡 |

前瞻属于短期候选行动的 Monte Carlo 比较，没有训练神经动力学、策略网络、价值网络，也不是 MuZero / MCTS。已知规则直接精确模拟，避免引入近似动力学误差。它使用的是均衡后续策略，仍会受候选宽度、短视叶估值和对手假设限制。

本机并发运行时，含前瞻策略的一整局平均耗时约 2.1–2.7 秒，轻量策略约 38–78 毫秒。这是整局墙钟时间，包含并发竞争、其他玩家和规则核验，不能视为精确的单步性能基准。前瞻组 768 局用时约 462 秒，四个 worker。

初始手牌按身份随座位轮换；初始先竞价者固定物理座位 0，以完整轮换控制位置影响。骰子按航次 / 掷骰轮 / 货物编码，策略看不到实际骰子种子，决策随机流与骰子独立。各策略共用基础种子，减少无关随机差异；策略导致装载或游戏长度变化后，经济环境仍会不同。

只在挑战赛统计被评估身份，陪测对手不混入同策略分数。置信区间以独立种子为组，同组座位 / 排列视为相关；均值采用组均值的标准误 ×1.96。最高 / 最低受样本量影响，尤其前瞻样本少；P05–P95是分数分布分位数，均值置信区间是均值估计的不确定性，两者不同。所有策略都未经本轮种子调参；结果只适用于当前固定对手池。

```powershell
node tools/report-tournament.mjs output/report-rebuilt --from-archive reports/2026-10-07
python tools/plot-tournament.py output/report-rebuilt
```

省略 `--from-archive` 时读取三组新比赛的原始输出。`tools/plot-tournament.py` 也可直接对已提交报告目录重绘图表。
